Batch transcription

  • Drop several video or audio files at once (on a window, the Dock icon, or with Open Media…) and they all go into one Batch Transcription window instead of a window each.
  • Files are transcribed one after another, with an overall progress bar and per-file status and progress. Cancel or retry a single file, or stop the whole batch.
  • Choose what's saved next to each file: a Transcriber project you can open and edit, plus SRT, WebVTT, plain text, Markdown or a SOAP note.
  • File › Batch Transcribe… (⇧⌘B) opens the window any time. A batch keeps running if you close it, with a notification when it finishes.
